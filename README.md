# Piano Presitel — Office Converter (download)

Public download page for the **standalone Office Converter** used by Piano Presitel.
It converts every old Office file in a folder or drive to the modern format:

- `.xls → .xlsx`  `.doc → .docx`  `.ppt → .pptx`  (and `.rtf → .docx`)
- Full fidelity — content, formatting, logos, shapes and charts are preserved.
- **LibreOffice is bundled — nothing to install.**

## Download & run
1. Go to **[Releases](../../releases/latest)** and download `PianoOfficeConverter.zip`.
2. Extract it, run **PianoOfficeConverter.exe** (Windows may warn "unknown publisher" → *More info → Run anyway*).
3. Browse to a folder or drive → **Convert folder**. Results appear in a `_converted` subfolder; originals are untouched.

> The app source lives in the main (private) project; this repo only hosts the downloadable build.
